# **App Name**: Musician's Toolkit

## Core Features:

- Interactive Tuner: Displays an interactive guitar tuner using real-time audio input.
- Customizable Metronome: Allows users to select BPM and time signatures to drive a metronome.
- Radio Player: Allows users to select a station to play.
- Chord Search: Tool which will help users to find chords on the Internet.
- Save Chords: Allows users to save searched chord files for later.
- Secure Authentication: Google Authentication for secure sign-in and data storage.
- Responsive UI: UI layout adapts to different screen sizes for accessibility.
- ChordPro Viewer: Parses and renders ChordPro files beautifully, with a built-in auto-scroller for hands-free practice.

## Style Guidelines:

- Background: Dark Navy (#0F0F23). This serves as the primary canvas, creating a dark-mode, tech-focused environment.
- Primary/Highlight: Electric Blue (#00D4FF). Used for active navigation states, primary buttons, and key interactive elements to guide the user's attention.
- Accent: Purple (#7C3AED). An analogous color used for secondary calls-to-action and visual flourishes, providing a vibrant contrast to the electric blue.
- Headline Font: Space Grotesk. A geometric sans-serif font used for all titles and major headings to convey a bold, futuristic feel.
- Body Font: Inter. A highly legible sans-serif font chosen for all paragraph text, labels, and UI descriptions for its clarity and clean appearance.
- Code Font: Source Code Pro. A monospace font used exclusively for rendering ChordPro content within the viewer, ensuring perfect alignment and readability of chords and lyrics.
- Use modern, flat design icons from the Font Awesome library.
- Fade-ins on page/component load.
- Slide-ups for modals and pop-up elements.
- Layout animations (AnimatePresence) for smooth transitions when switching between tabs or re-ordering lists.
